	*4. Checkout page (new feature)
	--added checkout page which was not there before clicking the button was doing nothing
	--for that i first created CheckoutForm in forms.py with fields like full_name, phone, email, address, city, state, pincode and payment_method
	--payment_method has 3 choices - Cash on Delivery, UPI, Card and i used RadioSelect widget for it
	--created checkout view in views.py
			def checkout(request, racket_id):
    			racket = get_object_or_404(rackets, id=racket_id)
    			if request.method == 'POST':
        			form = CheckoutForm(request.POST)
        			if form.is_valid():
            			return render(request, 'DBL/order_confirm.html', {
                			'racket': racket,
                			'order': form.cleaned_data,
            			})
    			else:
        			form = CheckoutForm()
    			return render(request, 'DBL/checkout.html', {'racket': racket, 'form': form})
	--added url for it in urls.py
			path('checkout/<int:racket_id>/', views.checkout, name='checkout'),
	--in buy.html changed the Proceed to Checkout button from <button> to <a href> pointing to checkout url
			<a href="{% url 'checkout' racket.id %}" class="btn-checkout">Proceed to Checkout</a>
	--after form submission it shows order_confirm.html with all the details of the order

	**important - when you have a button that needs to go to another page don't use <button> use <a href> with url tag**
