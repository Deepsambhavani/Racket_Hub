	*1. Checkout page (new feature)
	--before when we clicked "Proceed to Checkout" button nothing was happening because it was just a <button> tag with no action
	--big lesson - <button> inside a form submits the form but if it's outside a form it does nothing
	--for redirecting to a new page you have to use <a href> tag not button
			<a href="{% url 'checkout' racket.id %}">Proceed to Checkout</a>
	--first created CheckoutForm in forms.py with all the delivery fields
			full_name, phone, email, address_line1, address_line2, city, state, pincode
	--also added payment_method with 3 choices using ChoiceField
			PAYMENT_CHOICES = [
				('cod', 'Cash on Delivery'),
				('upi', 'UPI'),
				('card', 'Credit / Debit Card'),
			]
			payment_method = forms.ChoiceField(choices=PAYMENT_CHOICES, widget=forms.RadioSelect)
	--RadioSelect widget shows as round radio buttons instead of dropdown which looks better for payment
	--created checkout view in views.py passing the racket id so we can show order summary
			def checkout(request, racket_id):
				racket = get_object_or_404(rackets, id=racket_id)
				if request.method == 'POST':
					form = CheckoutForm(request.POST)
					if form.is_valid():
						return render(request, 'DBL/order_confirm.html', {
							'racket': racket,
							'order': form.cleaned_data,
						})
				else:
					form = CheckoutForm()
				return render(request, 'DBL/checkout.html', {'racket': racket, 'form': form})
	--form.cleaned_data is a dictionary of all the verified form values we can pass it to template directly
	--added url in urls.py
			path('checkout/<int:racket_id>/', views.checkout, name='checkout'),

	*5. Images understanding
	--images are saved in media/DBL/ folder
	--in model image field we store the path like 'DBL/filename.jpg' not the full path
	--Django adds MEDIA_URL in front when you call racket.image.url in template
	--so if MEDIA_URL = '/media/' then image.url becomes '/media/DBL/filename.jpg'
	--if image is not showing always check
		1. MEDIA_URL and MEDIA_ROOT set in settings.py
		2. + static(settings.MEDIA_URL...) added at end of urlpatterns in urls.py
		3. actual image file exists in media/DBL/ folder
		4. image field in db has the correct path stored
